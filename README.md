# Bulk Mail Dashboard

Hii Everyone! 👋

Welcome to my Bulk Mail Dashboard project! This is a sleek, modern, full-stack web application built with the MERN stack (MongoDB, Express.js, React, Node.js). It is designed to offer a professional and reliable way to send bulk emails by utilizing the official Gmail API (via Google OAuth 2.0), completely bypassing standard cloud SMTP restrictions.

---

## 📌 Project Overview

This project delivers a complete MERN-structured bulk mailing workflow with a premium dark charcoal-blue and bright accent blue UI/UX. It demonstrates advanced full-stack development principles such as integrating secure third-party APIs (Google OAuth 2.0), handling database modeling for email history, configuring secure environment variables, and achieving dual-platform deployment across Vercel and Render.

Developing this application helped me strengthen my understanding of full-stack API integration, resolving real-world cloud hosting limitations (like Render's port 465/587 SMTP blocks), managing MongoDB Atlas connections, and designing responsive, state-driven React interfaces.

---

## ✨ Features

* ✅ Reliable Bulk Mailing via Google's HTTP Gmail API 📨
* ✅ Secure Google OAuth 2.0 Authentication (Client ID & Refresh Tokens) 🔐
* ✅ Real-Time Email Tracking & Status Logging in MongoDB Atlas 🗄️
* ✅ Immersive Premium Dark Mode UI with Bright Blue Accents 🎨
* ✅ Production CORS Protection & Domain Whitelisting 🛡️
* ✅ Modern Form Input Validation & Loading State Spinners ⏳
* ✅ Decoupled Microservice Deployment (Vercel + Render) 🚀
* ✅ Fully Responsive Design across Desktop, Tablet, and Mobile 📱

---

## 🛠️ Technologies Used

* ⚛️ React.js (Vite, JSX, Components, Hooks, Axios)
* 🟢 Node.js & Express.js (REST API Server)
* 🍃 MongoDB & Mongoose (Cloud Database & Schema Modeling)
* 🔑 Google APIs (OAuth2 Client & Gmail API v1)
* 🎨 CSS3 (Custom Variables, Flexbox, Media Queries)
* ☁️ Vercel (Frontend Hosting) & Render (Backend Hosting)

---

## 🎯 Purpose of the Project

The main objective of this project is to practice and improve my full-stack web development skills by creating a functional, real-world utility application. Through this project, I gained hands-on experience in:

* Overcoming cloud deployment firewalls by swapping standard Nodemailer SMTP for HTTP-based API requests
* Structuring decoupled client and server environments (MERN architecture)
* Managing secure credentials and refresh tokens without exposing them in source code
* Connecting a Vite React frontend to a custom Express API using dynamic environment variables
* Deploying full-stack applications across independent cloud platforms
